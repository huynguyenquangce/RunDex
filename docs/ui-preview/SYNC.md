# UI preview sync

`index.html` is an interactive HTML replica of the app screens, for looking at the UI in a browser without a phone. It is generated by `scripts/build_ui_preview.py` from `scripts/ui-preview.template.html` and `src/backend/catalog/events.snapshot.yaml`.

- Last synced with the app at commit: `41a554e` (2026-11-06)
- Data refresh (automatic): GitHub Actions workflow `ui-preview.yml` rebuilds the file when the snapshot or the status logic changes.
- Screen changes (agent): after changing screens in `src/mobile`, ask Claude Code to run the `ui-preview-sync` agent (`.claude/agents/ui-preview-sync.md`); it updates the template and this file.
- Open it: double-click `index.html` (works offline). Jump to a state with the address, e.g. `#platform=android&screen=detail&slug=<slug>`, `#sheet=1`, `#sim=error&offline=1`, `#static=1` (no animations).
- Test: `src/backend/tests/test_ui_preview.py` checks that the preview's filters return the same counts as the API.
