# 01 — Project selection

- Date: 2026-11-06
- Tool/model: Claude Code (Sonnet 5.5)
- Goal: choose a practical, well-designed project for the challenge.

## Prompt (condensed from several turns)
```
Brainstorm project ideas (DevOps/security welcome). I prefer a web/app. If AI already generates and checks code, why add a checking step? [rejecting IaC idea]
...
My idea: a web/app tracking all running events and trails organized across Vietnam. Is it feasible? What is the pain point? Check whether similar products exist. Scope: all events, not only trail.
```

## Result summary
AI compared options, critiqued the DevOps ideas, assessed feasibility (data acquisition is the hard part), proposed AI-assisted poster/text extraction with human verification, and ran a market search.

## Manual fixes
Direction and final choice were mine; AI's DevOps and RuleLoop proposals were rejected.
